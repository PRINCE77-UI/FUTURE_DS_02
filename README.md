# 📊 Customer Retention & Churn Analysis Dashboard

## 📌 Project Overview

This project analyzes customer retention and churn behavior using the Telco Customer Churn dataset. An interactive Power BI dashboard was developed to identify churn patterns, customer segments, and key business insights that help improve customer retention strategies.

---

## 🎯 Objectives

- Analyze Customer Churn
- Measure Retention Rate
- Identify High-Risk Customers
- Compare Contract Types
- Analyze Internet Services
- Evaluate Payment Methods
- Generate Business Recommendations

---

## 🛠️ Tools Used

- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX
- Microsoft Word

---

## 📈 KPIs

- Total Customers
- Active Customers
- Churn Customers
- Churn Rate
- Retention Rate
- Average Monthly Charges
- Average Tenure

---

## 📊 Dashboard Features

- KPI Cards
- Customer Distribution
- Churn by Contract
- Churn by Internet Service
- Churn by Payment Method
- Gender Analysis
- Senior Citizen Analysis
- Interactive Slicers

---

## 💡 Business Insights

- Month-to-Month customers have the highest churn.
- Two-Year contract customers show the highest retention.
- Fiber Optic users are more likely to churn.
- Electronic Check customers have higher churn.
- Longer tenure customers are more loyal.
- Senior Citizens show relatively higher churn.

---

## 🚀 Recommendations

- Encourage customers to move to yearly contracts.
- Improve Fiber Optic service quality.
- Promote automatic payment methods.
- Launch loyalty rewards for long-term customers.
- Provide personalized offers to high-risk customers.
- Improve support for Senior Citizen customers.
